# 软件使用

软件分两部分，都在本仓库里：

| 部分 | 装在哪 | 干什么 |
|---|---|---|
| 固件（`firmware/`） | 刷进 ESP32-C3（只需刷一次） | 在小屏幕上画出画面 |
| 电脑端程序 `esp32-ai-usage.exe`（`host/`） | 装在 Windows 电脑上 | 查询额度，通过 USB 发给小硬件 |

---

## 一、给 ESP32 刷固件（只需一次）

刷固件用 [PlatformIO](https://platformio.org/)。最简单的两种装法（任选其一）：

- 装了 Python 的话：`pip install platformio`
- 或在 VSCode 里装 **PlatformIO IDE** 扩展

步骤：

1. 用 **USB 数据线**（注意别拿成只能充电的线）把 ESP32-C3 连到电脑；
2. 在仓库目录打开命令行，执行：

   ```bash
   cd firmware
   pio run -e esp32-c3 -t upload
   ```

   > 用的是 ESP32-S3 就把 `-e esp32-c3` 换成 `-e esp32-s3`。

3. 刷完屏幕出现 `AI Usage / Waiting for PC...`，固件就绪，等电脑端程序连上来：

   ![刷完固件的待机画面](./images/eu_waiting.JPEG)

> 接线说明：固件默认 OLED 接 SDA=GPIO4、SCL=GPIO3（按[硬件安装](./硬件安装.md)接线即可）。
> 如果你接了别的引脚，改 `firmware/platformio.ini` 里的 `-DPIN_SDA` / `-DPIN_SCL` 再刷一次。

## 二、电脑端程序 esp32-ai-usage.exe
最新版下载：https://github.com/0990/esp32-ai-usage/releases/latest

### 获取

- 直接去本仓库的 **Releases** 页下载 `esp32-ai-usage-*.exe`（推荐）；
- 或自行构建：需要 Go 1.21+ 和 MinGW-w64 gcc，运行 `host/build.bat` 即可，产物在 `host/bin/`。

### 前提

程序**读取本机已登录的 Codex / Claude Code / ReClaude / Kimi CLI 凭据**去查额度（不跑模型、不消耗额度），
所以电脑上要先正常登录过 Codex（`~/.codex`）、Claude Code（`~/.claude`）、ReClaude（`~/.reclaude/device.json`）或 Kimi CLI（`~/.kimi-code`），不需要另外填 key；使用 ReClaude 还要先运行 `reclaude` 启动 daemon。

### 使用
1. 双击运行 `esp32-ai-usage.exe`，弹出设置窗口。
   点右上角关闭只是**收进右下角托盘**，不会退出；托盘图标右键可退出。
![image1](./images/esp32-ai-usage.png)
2. 在「设置」页确认几项（默认基本可用）：
   - **监控对象**：要显示哪个的额度，可勾选一个或多个（`codex` / `claude` / `reclaude` / `kimi`）；勾多个时轮流翻页显示；
     `reclaude` 需要先运行 `reclaude` 启动本机 daemon；host 会通过其本地代理查询 5 小时和 1 周用量。
   - **OLED 亮度**：滑块范围 0–255，数值越大越亮，默认 143；点「保存」后立即调整。电脑端和 ESP32 都会记住设置，重启或重新连接后恢复。需使用支持亮度设置的新版固件。
   - **开机启动**：勾上就随电脑自动启动（默认不勾）；
   - **桌面悬浮窗**（Windows，可选）：打开「在桌面显示额度」，立即生效并自动保存，无需再点「保存」。
     「样式」可选 **雾白卡片**（上下两组细进度条，296×166）、**曜石仪表**（深色双列，348×150）、**极简窄条**（紧凑横向条目，330×132，默认）。
     三款均显示余量和本地重置时间；实色圆角卡片默认不透明，不再使用透明背景颜色键。
     切换样式会恢复该款默认尺寸，之后可用「宽度」「高度」分别调整，或直接拖动右下角；整体不透明度可在 40%–100% 调整。
     拖动顶部名称可放到任意显示器的位置，松手后自动保存；「回到右上角」可重置位置。顶部图钉切换置顶/置底：高亮图钉为置顶，灰色斜线图钉为置底，切换后立即更新。省略号菜单可直接切换样式。
     「层级」可选「始终置顶」或「始终置底」。这些设置均立即生效并自动保存，重启后沿用；
     置底时其他窗口可覆盖悬浮窗，可从主窗口或托盘操作显示开关。屏幕布局变化导致窗口完全不可见时会恢复到最近屏幕。
     多个监控对象按「轮播间隔」切换，自定义中转站显示名称和剩余余额；过期数据会提示。
     不连接 ESP32 也能使用，主窗口关闭到托盘后仍显示。托盘右键的「显示桌面额度悬浮窗」可随时开关；
     悬浮窗右上角的关闭按钮也会关闭并保存此开关，下次启动沿用。默认关闭，配置字段为 `desktop_overlay`，
     样式为 `overlay_style`（`paper` / `obsidian` / `strip`），尺寸为 `overlay_width` / `overlay_height`，整体不透明度为 `overlay_opacity`，层级为 `overlay_layer`（`top` / `bottom`）。
     旧配置首次升级自动使用极简窄条，保留窗口位置、层级和监控对象；
   - **运行标志钩子**（可选）：点「安装」后，Claude Code / Codex 正在干活时屏幕左下角会有三个点跑动、板载灯蓝色呼吸；
     它们停下来等你授权时图标右上角出现脉动的「!」角标、灯紫色快闪。原理是往 `~/.claude/settings.json` 和 `~/.codex/hooks.json`
     写入指向本程序本地端口的 hook。Claude Code 新开的会话即生效；**Codex 需要在 Codex 里输入 `/hooks` 审核并信任一次**，
     否则不会执行。不想要了点「移除」即可清理干净；
   - **自定义对象**：在「监控对象」中点「新增自定义对象」，手动选择 `sub2api` 或 `newapi`，填写名称、Base URL 和 API key；
     Base URL 支持站点根地址（如 `https://relay.example`）或带 `/v1` 的地址。可添加多个对象，分别勾选、编辑或删除，点设置页「保存」后生效。
     可以取消所有内置对象，仅勾选自定义对象。OLED 上 `sub2api` 显示 S2 图标，`newapi` 显示 N 图标，两种页面都只显示余额。需同时更新电脑端和固件。
     中转站查询不再读取 Codex 的 `config.toml`、Claude 的 `settings.json` 或 cc-switch 数据库；旧中转站需手动重新添加。
   - **更多**（点开折叠）：串口默认 `AUTO` 自动找；**用 Claude 的注意**——如果你的 Claude 是走中转的，
     要把「Claude 端点」填成你的中转地址（形如 `https://你的中转域名`），否则 Claude 页会显示 ERR。
3. 点「保存」，把小硬件用 USB 线插上电脑。窗口底部显示「串口: COMx @ 115200」就连上了，
   屏幕随后开始显示额度。想马上看到最新数据，点「立即刷新使用量」。

### 常见问题

| 现象 | 处理 |
|---|---|
| 屏幕一直 `Waiting for PC...` | 确认电脑端程序在运行、底部串口状态已连接；未连接时把「更多」里的串口改成具体的 `COMx` 再保存 |
| 底部显示「串口: 未连接」 | 换根 USB 数据线 / 换个 USB 口，插好后点一次「保存」触发重连 |
| Codex 页显示 `ERR` | 本机没登录 Codex，或访问不了 chatgpt.com（在「更多」里配代理） |
| Claude 页显示 `ERR` | Claude 走中转的话，「Claude 端点」要填你的中转地址（见上文） |
| Kimi 页显示 `ERR` | 本机没登录 Kimi CLI；或 token 已过期（仅 15 分钟有效）——随便用一次 Kimi CLI（发一条消息）即自动刷新恢复 |
| 中转站页取不到数 | 看「活动日志」里的报错；检查自定义对象的类型、Base URL 和 API key 是否正确 |
| 数据多久刷新一次 | 默认 5 分钟一次（可在「更多」里改），订阅凭据变动或保存配置后会自动立即刷新 |
| 装了运行标志钩子但屏幕没反应 | Codex 要先在其 TUI 里 `/hooks` 信任新钩子；Claude Code 要新开会话；看「活动日志」有没有 `activity` 行，以及本机 `52736` 端口是否被占 |
